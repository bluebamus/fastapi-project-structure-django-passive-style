PROJECT GUIDE

API 레퍼런스

app.openapi()의 38개 operation과 각 operation의 접근 수준을 정리합니다.

허브부팅설계 API요청인증 기능개발운영

도식은 고정 버전 Mermaid CDN(11.12.0)을 사용합니다. 인터넷이 없어도 본문·표·도식 원문을 읽을 수 있습니다.

공통 규칙

  • 기능 API는 /api/v1 아래에 있으며 health/readiness는 루트 경로입니다.
  • 입력은 Pydantic 스키마로 검증되고 도메인·저장소 오류는 공통 오류 응답으로 변환됩니다.
  • public_write는 익명 쓰기입니다. rate limit은 register·login에만 걸립니다(429 + Retry-After).
  • 정확한 요청·응답 스키마는 DEBUG=true일 때만 열리는 /docs·/openapi.json에서 확인합니다.
  • /admin은 ADMIN_DISABLED=false(기본)일 때 마운트되는 SQLAdmin 하위 앱이라 이 표와 OpenAPI에 없습니다.

코드 근거

접근 수준 열은 AccessPolicyGuard().levels(app)의 판정이고, 추가 판정 열은 서비스가 하는 소유자·본인 확인입니다.

  • app/core/security/access.py — 접근 수준 선언과 AccessPolicyGuard(기본 거부)
  • app/core/apps/wiring.py — 설치 앱 라우터 조립(install_routers)
  • tests/test_authorization_policy.py — 오퍼레이션별 의도한 접근 수준 회귀 표
  • tests/test_route_inventory.py — 공개 경로 목록 고정
  • tests/test_docs_guide_site.py — 이 표와 OpenAPI × 가드 판정 대조
  • app/features/home/api/routers/v1/home.py
