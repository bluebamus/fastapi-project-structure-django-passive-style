PROJECT GUIDE

테스트와 검증

단위·계약·통합·E2E 테스트의 역할과 실행 기준을 설명합니다.

허브부팅설계 API요청인증 기능개발운영

도식은 고정 버전 Mermaid CDN(11.12.0)을 사용합니다. 인터넷이 없어도 본문·표·도식 원문을 읽을 수 있습니다.

기본 명령

uv run python -m pytest -m "not mysql and not browser"   # 외부 인프라 불필요 (SQLite·가짜 Redis)
uv run ruff check . && uv run ruff format --check . && uv run mypy .
uv run python -m scripts.review_gate --fast

기본 게이트는 mysql·browser 마커를 뺍니다. browser 테스트는 REDIS_HOST·REDIS_PORT로 실제 Redis가 필요하고, e2e 테스트는 -m e2e로 지정했을 때만 수집됩니다(REDIS_HOST=127.0.0.1 REDIS_PORT=16393 uv run python -m pytest -m e2e). 준비물은 README 테스트와 개발 가이드 §6을 따릅니다.

정확한 marker와 검사 옵션은 pyproject.toml 및 테스트 파일을 기준으로 합니다.

변경 완료 조건

성공 경로만이 아니라 잘못된 입력, 미인증, 권한 부족, 없음, 충돌, 저장소 실패를 검증합니다. 외부 서비스가 필요한 테스트를 생략했다면 결과에 명시하고 CI에서 보완합니다.
