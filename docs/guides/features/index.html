주요 기능 안내

허브부팅설계 API요청인증 기능개발운영

도식은 고정 버전 Mermaid CDN(11.12.0)을 사용합니다. 인터넷이 없어도 본문·표·도식 원문을 읽을 수 있습니다.

기능 경계

각 기능은 자체 라우터·서비스·저장소·스키마를 한 디렉터리에 모읍니다. 기능은 config.INSTALLED_APPS의 AppConfig 한 줄로 설치되고, 공통으로 쓰는 것은 app/core에 둡니다. 다른 기능을 import 하는 곳은 auth → user(사용자 모델·저장소) 하나뿐입니다.
