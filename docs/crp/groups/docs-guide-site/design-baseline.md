## 3. 설계 결정 (ADR)

| ADR | 결정 | 이유 |
|---|---|---|
| ADR-001 | 코드가 정답 — 문서·docstring·테스트만 고친다. 코드 동작은 바꾸지 않는다 | 문서 정합성 작업의 전제 |
| ADR-002 | API 표의 접근 수준 열은 `AccessPolicyGuard().levels(app)` 판정값(public·public_write·login·superuser), 소유자·본인 확인은 별도 열 | 계약 테스트가 표를 가드 판정과 그대로 대조할 수 있다 |
| ADR-003 | 설정 표는 `config.py` Settings 필드 78개 전부를 코드 기본값·Field 설명으로 싣는다(`.env.example` 주석을 옮기지 않는다) | 인접 주석을 옮기며 설명이 어긋났던 원인 제거 |
| ADR-004 | Mermaid 는 기존 안내서와 같은 `mermaid@11.12.0` 로더·CDN 실패 안내를 각 페이지에 인라인으로 둔다 | `file://` 로 열 때 외부 모듈 스크립트가 막히지 않게 |
| ADR-005 | "CODE-VERIFIED GUIDE" 라벨은 `PROJECT GUIDE` 로 바꾼다 | 검증 사실(기준 커밋·방법)을 라벨로 보장할 수 없다 — 대신 계약 테스트가 표를 지킨다 |
