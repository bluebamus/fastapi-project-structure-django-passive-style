환경 설정 레퍼런스

.env.example과 설정 모델을 기준으로 값의 유입과 검증 책임을 설명합니다.

허브부팅설계 API요청인증 기능개발운영

사용 원칙

설정의 단일 진입점은 config.py이며 환경 변수 이름과 예시는 .env.example에서 확인합니다. 운영 비밀은 저장소에 커밋하지 않고 비밀 관리 시스템에서 주입합니다.

예제 환경 변수

변수예제 값인접 설명
PROJECT_NAMEfastapi-project-structure-django-…프로젝트 이름 (Scalar 문서 제목, 관리자 페이지 제목에 표시. 코드 기본값: FastAPI Project)
VERSION1.0.0애플리케이션 버전 (GET /health 응답의 version. 코드 기본값: 0.1.0)
DEBUGtrueENV 가 staging/production 이면 true 일 때 기동이 거부된다 (LOG_LEVEL=DEBUG 도 동일).
ADMIN_DISABLEDfalse로그인 시도는 API 로그인과 같은 AUTH_LOGIN_* 한도로 센다(초과 시 429 + Retry-After).
ENVdevelopment/health 응답에는 포함되지 않는다.
SERVER_HOST0.0.0.0관리 화면을 외부에 노출할 이유가 없으면 프록시에서 /admin 을 내부망으로 제한한다.
SERVER_PORT8000
TIME_ZONEAsia/Seoul예시: Asia/Seoul, UTC, America/New_York
MYSQL_HOSTlocalhostMySQL 서버 호스트 (IP 또는 도메인)
MYSQL_PORT3306MySQL 서버 포트
MYSQL_USERrootMySQL 접속 사용자명
MYSQL_PASSWORDchange-this-mysql-passwordMySQL 접속 비밀번호 — 예시 값·빈 값이면 test 외 모든 ENV 에서 기동이 실패한다
MYSQL_DATABASEfastapi_db사용할 데이터베이스 이름
DB_ROUTER_ENABLEDfalse구현: app/core/db/router.py
DB_REPLICATION_ENABLEDfalse- false: 라우터를 켜도 replica 가 없으므로 읽기도 primary 로 나간다.
DB_READ_STICKY_AFTER_WRITEtruefalse 로 두면 읽기 분산은 늘어나지만 read-after-write 일관성을 잃는다.
MYSQL_REPLICA_HOSTS[]예: MYSQL_REPLICA_HOSTS=["10.0.0.11", "replica-b.example.com:3307"]
MYSQL_REPLICA_PORT3306포트를 명시하지 않은 replica 에 적용할 기본 포트
REDIS_HOSTlocalhostRedis 서버 호스트
REDIS_PORT6379Redis 서버 포트
REDIS_DB0Redis 데이터베이스 번호 (0-15)
REDIS_PASSWORDRedis 비밀번호 (설정하지 않으면 인증 없이 접속)
CORS_ALLOW_ORIGINS["*"]특정 Origin만 허용: ["http://localhost:3000", "https://example.com"]
CORS_ALLOW_CREDENTIALSfalseCORS_ALLOW_CREDENTIALS=true
CORS_ALLOW_METHODS["GET", "POST", "PUT", "DELETE", …허용할 HTTP 메서드 (JSON 배열 형식)
CORS_ALLOW_HEADERS["*"]허용할 HTTP 헤더 (JSON 배열 형식)
CORS_MAX_AGE600Preflight 요청 캐시 시간 (초)
LOG_CONSOLE_ENABLEDtrueuvicorn 자체 로깅을 쓰므로 그 줄은 이 값과 무관하다.
LOG_FILE_ENABLEDtrue파일 로그 출력 활성화 (ENV=staging|production 일 때만 파일 핸들러가 붙는다)
LOG_FILE_LEVELINFO파일 로그 레벨 (파일에는 INFO 이상만 기록하는 것이 일반적)
LOG_DIRlogs로그 파일 저장 디렉토리 (프로젝트 루트 기준 상대 경로)
LOG_MAX_SIZE_MB10하루 안 분할 크기 (MB, 0 = 크기 분할 없음)
LOG_RETENTION_DAYS30회전된 파일 보관 일수 — 더 오래된 날짜 파일·분할 파일을 회전 시점에 지운다 (0 = 지우지 않음)
ACCESS_LOG_ENABLEDtruetrue: 모든 API 요청에 대해 접속 로그를 DB에 저장
ACCESS_LOG_RETENTION_DAYS365beat 프로세스가 떠 있어야 돈다: uv run celery -A app.celery.app beat --loglevel=info
TRUSTED_PROXY_HOPS0(README 「운영 배포 체크리스트」).
SESSION_COOKIE_NAMEsession/admin 세션 쿠키 이름(admin_session)과 같으면 기동이 실패한다(관리자 쿠키가 접속 로그에 남는다).
SESSION_SECRET_KEYchange-this-session-secret-key**기동이 실패한다**(config.validate_deployment_safety).
ACCESS_TOKEN_SECRET_KEYchange-this-access-token-secret-keyACCESS/REFRESH 키가 같으면 **기동이 실패한다**(config.validate_deployment_safety).
REFRESH_TOKEN_SECRET_KEYchange-this-refresh-token-secret-key
ACCESS_TOKEN_EXPIRE_MINUTES15access 토큰은 즉시 폐기 수단이 없다 — 짧게 두고 refresh 회전·폐기로 세션을 관리한다.
REFRESH_TOKEN_EXPIRE_DAYS7Redis 의 refresh 기록(auth:rt:*)·family 폐기 표시의 TTL 도 이 값이다.

확장 방법

  1. 설정 필드를 타입과 안전한 기본값으로 추가합니다.
  2. .env.example에는 비밀이 아닌 예시와 설명을 추가합니다.
  3. 서로 의존하는 값은 설정 검증 단계에서 빠르게 실패시킵니다.
  4. 배포 매니페스트와 테스트 fixture를 함께 갱신합니다.
