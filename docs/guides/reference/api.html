읽는 법

이 페이지는 실행 중인 FastAPI 애플리케이션의 app.openapi() 결과에서 생성했습니다. 라우터 prefix, HTTP 메서드, operationId, 파라미터, 요청·응답 스키마가 실제 코드와 같은 조립 경로를 거칩니다.

경로 23개, 오퍼레이션 38개, 스키마 36개. OpenAPI의 security 선언은 인증 필요 여부의 한 근거이며, 소유권 검사는 Service 계층에서 추가로 수행될 수 있습니다.

POST /api/v1/auth/login

로그인(OAuth2 password)

username/password(form)로 access·refresh 토큰을 발급합니다. ip 기준과 ip+username 기준 레이트 리밋이 걸려 있고, 성공하면 ip+username 카운터를 초기화합니다.

operationId: authLogin · 인증 선언: OpenAPI상 없음 · 요청 본문: Body_authLogin

파라미터위치필수형식설명
없음

POST /api/v1/auth/logout

로그아웃

Refresh Token 의 family 를 폐기합니다(멱등). access 토큰은 만료까지 유효하므로 클라이언트가 버립니다.

operationId: authLogout · 인증 선언: OpenAPI상 없음 · 요청 본문: RefreshRequest

없음
