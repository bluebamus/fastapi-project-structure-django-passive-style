## 1. 목적 / 배경

`orm-raw-repository` 그룹(Phase 0~7, `aec451d`)이 Raw Base·예제 2종·게이트·검사를 모두
만들었다. 그런데 그 결과가 **CRP 문서와 설계 문서에만 기록**됐고, 학습자가 읽는 문서
(README·QUICKSTART·ARCHITECTURE·project-guide)는 Phase 3 시점에 멈춰 있다.

사용자 요구는 "이 구조를 쓰는 개발자가 Django 스타일 수동 등록과 ORM/Raw 두 워크플로를
**이해하고 학습**할 수 있어야 한다" 이다. 두 주제 중 Django 스타일만 달성돼 있다.

2026-08-20 재검수에서 한 단계 더 나쁜 것이 나왔다: `project-guide` 는 뒤처진 게 아니라
**틀렸다**. 존재하지 않는 세션 API 3개를 가르친다(L-007). 그리고 그것이 살아남은 이유는
죽은 참조 검사가 `project-guide` 를 훑지 않기 때문이다(L-008).

근거: `audit-report.md` (측정·결함·작업 목록 전문)

## 4. 불가침 제약

- **INV-L1** 코드는 바뀌지 않는다. diff 는 문서와 테스트에만 나타난다
- **INV-L2** `scripts/review_gate.py` 8단계가 통과한다 (T-4a~T-1 중간 상태 제외 — 한 커밋으로 묶음)
- **INV-L3** `docs/project-guide/v1.0/` 을 지우지 않는다
- **INV-L4** 학습 문서가 설계 문서를 복사하지 않는다
- **INV-L5** 문서가 코드에 없는 공개 심볼을 가르치지 않는다 (L-007 재발 방지)
